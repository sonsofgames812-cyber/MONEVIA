# MONEVIA Standalone Demo

A mobile-friendly, front-end-only prototype of the MONEVIA earning marketplace concept. It uses HTML, CSS, JavaScript, and browser `localStorage`. It does not require Supabase or another service to run locally.

## Run it
1. Download and extract the ZIP.
2. Open `public/index.html` in a modern browser.
3. Use **Create demo account** to make a local demo profile.
4. Explore sample tasks, sample marketplace listings, demo wallet activity, and the demo cart.

For best results, use a simple local static server if your editor provides one. No package installation is required.

## Important limitations
- This is a demonstration, not a production earning platform.
- Demo profile and activity data stay in this browser on this device. Clearing browser storage may erase them.
- There is no secure authentication, shared database, server, real task verification, real marketplace inventory, or payment processing.
- Sample rewards and balances are illustrative only. No real money is earned, held, or transferred.
- Do not enter real passwords, banking details, or payment information.
- A static rebuild does not automatically remove a Google Safe Browsing warning. Investigate the flagged domain separately before asking Google to review it.
